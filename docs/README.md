My Python Lab Project

A beginner-friendly Python project demonstrating functions, user input, basic calculations, and Git/GitHub version control.

## 📌 Project Overview

This project was created as part of a Python programming lab. It contains reusable Python functions and a main program that allows the user to interact with the application through the terminal.

## 🚀 Features

* Calculate the square of a number
* Check whether a number is even or odd
* Convert Celsius to Fahrenheit
* Generate a personalized greeting
* Demonstrate Python modules and functions
* Use Git branches and GitHub for version control

## ▶️ How to Run

1. Clone the repository:

```bash
       git clone https://github.com/takaldaiman-cell/python-lab.git
```

2. Open the project:

```bash
cd python-lab
```

3. Run the Python program:

```bash
     python main.py
```

## 🌿 Branch Workflow

The project uses Git branches for feature development.

Main branch:

```text
main
```

Feature branch:

```text
feature/add-greeting
```

The `feature/add-greeting` branch adds the `greet(name)` function and demonstrates the use of pull requests on GitHub.
